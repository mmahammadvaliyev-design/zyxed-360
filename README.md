# Zyxed 360 — конструктор 360°-туров

Офлайн-конструктор туров по сферическим панорамам. **Бесплатно, без сервера,
без API-ключей.** Все данные хранятся только на вашем устройстве (IndexedDB).
Ставится на телефон как PWA.

## Что умеет

- **Несколько туров** — каждый со своим набором панорам, независимо друг от друга.
- **Импорт снимков** — любые сферические панорамы (equirectangular, 2:1): из режима
  «Панорама 360» на телефоне, с экшн-камеры или из Google Street View.
- **Переходы между панорамами** — точки на сфере с подписью, ведущие на другую
  панораму; расставляются прямо в туре или одной кнопкой «Связать по кругу».
- **Просмотр** — свайп/мышь, щипок и колесо на зум, автоповорот, поворот по
  наклону телефона, полный экран.
- **Публикация** — кнопка «Экспорт» собирает ZIP с готовым сайтом тура. Загружаете
  его на любой бесплатный статический хостинг (GitHub Pages, Netlify, Vercel) —
  и тур доступен по ссылке, без нашего участия и без сервера.

## Запуск

Нужен Node.js 18+ ([nodejs.org](https://nodejs.org)).

```bash
npm install     # один раз
npm run dev     # запустить локально → http://localhost:5173
```

## Сборка и хостинг самого приложения

```bash
npm run build    # готовая статика в dist/
npm run preview  # проверить собранную версию локально
```

`dist/` можно бесплатно выложить на GitHub Pages, Netlify или Vercel.

**Или вообще без хостинга.** `npm run build` сам чинит `dist/index.html`
(скрипт `scripts/fix-offline-html.mjs`, шаг `postbuild`) так, что его можно
открыть прямо двойным кликом с диска — без сервера и без интернета. Причина
та же, что и с экспортом тура (см. ниже): Chrome блокирует `<script
type="module">` под `file://`, поэтому шаг после сборки убирает `type="module"`
(бандл — один файл без code-splitting, ему такая семантика и не нужна).
Просто скопируйте папку `dist/` куда угодно (на комп, на флешку, в память
телефона) — `dist/index.html` откроется в браузере и будет работать
полностью офлайн, данные останутся в IndexedDB того браузера, где открыт файл.

## Как устроена публикация тура

Ключевая идея: движок рендера панорамы (`src/engine/`) не зависит от React
и Dexie — это чистый TypeScript + WebGL. Он используется дважды:

1. **В самом приложении** — для просмотра и редактирования тура.
2. **В отдельном автономном плеере** (`player/`) — лёгкой vanilla-JS страничке
   (≈6 КБ gzip), которая умеет только показывать готовый тур.

Плеер собирается отдельно (`npm run build:player`) прямо в `public/player` —
он входит и в сборку самого приложения (для предпросмотра), и используется
при экспорте: кнопка «Экспорт» в редакторе тура берёт готовые файлы плеера,
добавляет `data.json` (сцены и переходы) и картинки панорам — и упаковывает
всё в ZIP через `fflate` прямо в браузере. Собирать ничего на лету не нужно.

## Ограничения (осознанные, для MVP)

- Работает офлайн и хранит всё в браузере — нет синхронизации между устройствами.
- Экспортированный тур — статические файлы; чтобы поделиться ссылкой, нужно
  один раз загрузить их на любой бесплатный хостинг самостоятельно.
- Распознавание пропорций панорамы простое: приложение предупреждает, если
  снимок не 2:1, но всё равно позволяет его использовать.
